# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates:

| Version | Supported |
|--------|-----------|
| Main / Latest | ✅ Yes |
| Older versions | ❌ No |

---

## Reporting a Vulnerability

The AkubuikeOhaFixit team takes security seriously.

If you discover a security vulnerability, please **do not open a public issue**.

### ✅ How to report
- Use **GitHub Private Vulnerability Reporting**, if enabled  
  **OR**
- Email us directly at: **akubuikeohafixit@gmail.com**

Please include:
- A clear description of the vulnerability
- Steps to reproduce the issue
- Any relevant screenshots, logs, or proof of concept
- The potential impact of the vulnerability

---

## What to Expect

- We will **acknowledge receipt** of your report as soon as possible
- We will **investigate and validate** the issue
- If confirmed, we will work on a fix and release a security update
- You will be notified once the issue is resolved

---

## Responsible Disclosure

We kindly request that you:
- Avoid publicly disclosing the vulnerability before it is fixed
- Give us reasonable time to investigate and patch the issue

Responsible disclosure helps keep users and systems safe.

---

## Security Best Practices

This project follows common security best practices, including:
- Dependency vulnerability monitoring (Dependabot)
- Secret scanning to prevent credential leaks
- Regular updates and reviews of third-party libraries
- Secure coding standards

---

Thank you for helping keep this project and its users secure.
